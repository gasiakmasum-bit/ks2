# ORBITA — симулятор апгрейдера скінів CS2 (React + Vite)

Гра на **віртуальній валюті ₵**. Реальних скінів і грошей немає, вивід неможливий.
Супутник облітає орбіту й зупиняється; якщо він у зеленій зоні, апгрейд вдався.

## Запуск
```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # збірка в dist/ для будь-якого статичного хостингу
```

## Структура
- `src/App.jsx` — стан гри та розкладка
- Магазин: вкладка «Магазин» (пошук, ціна від/до, кошик, сторінки, «Купити й у ставку»)
- `src/components/` — Header, Feed (стрічка), Gauge (орбіта), SkinCard, Photo
- `src/lib/game.js` — каталог, ціни (Skinport або орієнтовні), чесний roll SHA-256, збереження
- `src/lib/fx.js` — спалах і уламки при виграші, плавна зміна числа
- `src/lib/sound.js` — усі звуки, синтезовані через Web Audio (файлів немає): наведення, клік, вибір, тріск храповика під час обертання, виграш, програш, монети, продаж
- `src/data/skins.json` — 17 893 предмети з фото (Steam CDN, база CSGO-API): скіни, стікери, кейси й капсули, брелоки, агенти, патчі, музика, графіті, монети й значки, хайлайти, інструменти; фільтр за категорією в магазині й у цілі апгрейду; `npm run update-skins` оновлює

Логотип: `src/components/Logo.jsx` (гекс-значок, прицільне кільце, стрілка, супутник; крутиться під час апгрейду) і `public/logo.svg`. Назву й кольори легко змінити в `Header.jsx` і `src/styles.css` (змінні в `:root`).

## Кейси
Окрема вкладка «Кейси» у верхній навігації (повноцінна сторінка): 42 кейси з реальним складом (CSGO-API), смішні назви й 6 тематичних збірок (`src/data/caseNames.js`) з фільтром і пошуком.
- Шанси як у CS2: Армійська 79.92% · Обмежена 15.98% · Засекречена 3.2% · Таємна 0.64% · ★ ножі/рукавиці 0.26%; всередині рідкості предмети рівноймовірні.
- Ціна кейса = середня вартість дропу (EV) ÷ 0.9, тобто повернення ≈90%; на сторінці кейса видно EV, шанс окупитись, топ-приз і шанси кожного предмета.
- Дроп чесний: SHA-256(сід:клієнтський сід:c<номер>), хеш сіду видно до відкриття, сід і розрахунок — після (блок «Перевірка чесності»).
- Анімація: тряска кейса, рулетка зі звуком храповика, підсвітка виграшного предмета, конфеті й банер для рідкісних; відкриття ×1/×2/×3/×5, «Продати все».
- Стрічка рулетки — візуальна (рідкісні предмети в ній трохи частіші), результат вирішує хеш.

## Мобільна версія (≤760px)
- Нижня навігація з іконками (Апгрейд · Кейси · Інвентар · Магазин · Нагороди), шапка зведена до лого, балансу й аватара; «Звук» та «Історія» — в меню аватара; випадаючі панелі стають шторками над навігацією.
- Липка панель над навігацією: шанс, множник і кнопка «Апгрейд»; у вкладці «Магазин» з непорожнім кошиком — кошик (очистити, «У ставку», «Купити»). Під час апгрейду сторінка сама піднімається до орбіти, у кейсах — до рулетки; вібровідгук на результат.
- Сітка по 2 колонки без вкладеного скролу, великі зони дотику (≥40px), поля вводу 16px (iOS не зумить), повзунок із великим «бігунком», safe-area для вирізів.
- Продуктивність: пошук по каталогу без повторного сортування (один раз за ціною + `useDeferredValue`), `JSON.parse` для великих даних, окремі чанки `vendor`/`data`, `content-visibility` для довгих списків кейсів, без `backdrop-filter` і `background-attachment:fixed`, без нескінченних анімацій на десятках карток, `decoding="async"` для фото; сплеш у `index.html` показується до завантаження JS.
- Усі мобільні стилі — в кінці `src/styles.css`; десктоп не змінено.
